# Prompt 002 — Vue frontend

Date: 2026-09-11

Build a simple Vue 3 frontend in frontend/ with a text input for hotel
name, a Search button, and a results table with columns hotel_name, city,
trip_name, check_in, check_out, nightly_rate_usd. Call the FastAPI
/search endpoint at http://127.0.0.1:8123 and show a clear 'No results
found' message when the array is empty.
